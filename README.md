# 🚀 Ankit Portfolio Website

Modern Personal Portfolio Website using HTML, CSS and JavaScript.

---

# 📌 Project Overview

This is a responsive and animated developer portfolio website created for showcasing:

- About Me
- Education
- Skills
- Projects
- Certificates
- Contact Details

The website has modern UI design, smooth animations, glassmorphism effects, typing effect and responsive layout.

---

# 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Flaticon Icons
